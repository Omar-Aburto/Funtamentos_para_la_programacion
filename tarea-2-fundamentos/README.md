**Autor:** Omar ABurto 
**Fecha:** 28 de agosto de 2026

## Descripción del Proyecto
 El código analiza datos simulados sobre el gasto mensual 
 en transporte público de un grupo de usuarios, con un enfoque particular
 en el impacto del beneficio de la Tarjeta Nacional Estudiantil (TNE).

## Estructura de los Datos

* `gasto_mensual`: Gasto total incurrido al mes en transporte (expresado en pesos chilenos).
* `viajes_sem`: Número estimado de viajes realizados a la semana por cada usuario.
* `usa_tne`: Que indica si el usuario hace uso del beneficio de tarifa escolar.

## Instrucciones de Uso (Paso a Paso)
Para correr este análisis de forma local en tu computador, sigue estas instrucciones paso a paso:

1. **Abrir RStudio:** Inicia la aplicación RStudio en tu equipo.
2. **Cargar el Proyecto:** Dirígete al menú superior `File` > `Open Project...` y selecciona el archivo `.Rproj` que contiene las carpetas de este curso.
3. **Abrir el Script:** En el panel inferior derecho (en la pestaña *Files*), navega hasta la carpeta llamada `scripts/` y haz doble clic para abrir el archivo `tarea_s3.R`.
4. **Ejecutar el Código:** Sitúa el cursor del mouse en la primera línea de código del script. Presiona las teclas `Ctrl + Enter` (en Windows/Linux) o `Cmd + Enter` (en macOS) consecutivamente para correr el código línea por línea.
5. **Revisar Resultados:** Observa el panel inferior izquierdo (la pestaña *Console*) para ver cómo se calculan e imprimen las operaciones estadísticas y lee atentamente los comentarios explicativos incluidos en el script.
