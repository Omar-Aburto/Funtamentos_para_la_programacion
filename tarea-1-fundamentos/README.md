# Variación del pasaje interurbano (TNE vs. Normal)

**Qué hace:** 
Este proyecto calcula y compara la tasa de variación porcentual del precio 
de los pasajes de transporte interurbano entre los años 2025 y 2026,
contrastando el impacto en estudiantes (con TNE) frente al público general (sin TNE).

**Datos:** 
Se utilizan datos de precios reales ingresados manualmente en el script.
El pasaje estudiante (TNE) pasó de $500 a $750,
y el pasaje normal de $1500 a $2100.

**Cómo correrlo:**
1. Clona este repositorio o descárgalo en tu computador.
2. Abre el archivo `tarea1-fundamentos.Rproj` en RStudio para cargar el proyecto.
3. Abre el archivo ubicado en la carpeta `scripts/` llamado `01_primeros_pasos.R`.
4. Ejecuta el código línea por línea para ver los resultados en la consola.
